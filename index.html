Como usar o aplicativo

Use os controles deslizantes para ajustar:

  • Temperatura: define o calor dentro da estufa.
  • Umidade do Ar: controla o ambiente de atmosfera.
  • Umidade do Solo: mostra a água disponível para a planta.

O painel à direita mostra o status atual:

  • Excelente: condições boas para o tomate.
  • Estresse Térmico: temperatura fora do ideal.
  • Solo Seco: precisa regar menos ou melhor.
  • Risco de Fungos: ar muito úmido.

Como foi feito

O projeto foi construído com HTML, CSS e JavaScript puro em um só arquivo.

O layout usa um painel principal com controles e status, enquanto o script calcula o retorno ao mover os sliders.

O efeito visual inclui um fundo degradê e tomates animados caindo para deixar o app mais atraente.
